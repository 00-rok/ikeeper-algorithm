# i-Keeper 개발 알고리즘 과제

문제는 정올(<http://jungol.co.kr/>)에서 풀고, 이 레포에 **Pull Request(PR)** 로 제출합니다.

## 제출 방법

> **처음이라면 [제출 방법 안내](제출방법.md) 를 꼭 읽어 주세요.** git 몰라도 웹에서 제출할 수 있습니다.

요약:
1. 문제 하나당 파일 3개를 **본인 GitHub 아이디**로 준비 → `아이디.c` (코드), `아이디.png` ('맞았습니다' 캡처), `아이디.md` ([풀이 템플릿](_template/풀이템플릿.md))
2. 푼 문제 폴더 → **Add file → Upload files** → 끌어다 놓기 → **Propose changes**
3. **Create pull request** (제목: `[2회차] 이름`)
4. PR 아래 자동 검사가 초록색 체크인지 확인

## 규칙

- **마감:** 각 회차 마감 시각까지 PR이 열려 있어야 제출로 인정합니다. 마감 후 수정은 반영하지 않습니다.
- **본인 파일만** 올립니다. 다른 사람 파일이나 공용 파일을 건드리면 자동 검사가 실패합니다.
- **AI 활용:** 본인 힘으로 먼저 고민하는 것을 권장합니다. AI의 도움을 받았다면 풀이 `.md` 에
  어떤 고민을 했는지와 **AI에 입력한 프롬프트 원문**을 반드시 적어 주세요.
- 공개 레포이므로 다른 사람의 제출물을 볼 수 있지만, 그대로 옮기는 것은 금지입니다.
- 개발 재학생(신입·기존) 평가 대상이며, 총 해결 문제 비율 미달 시 제명/경고 규정이 적용됩니다.

문의는 교육부장에게 카카오톡으로 해 주세요.
