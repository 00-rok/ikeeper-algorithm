# i-Keeper 개발 알고리즘 과제

i-Keeper 개발 재학생(신입·기존) 알고리즘 과제 제출 레포지토리입니다.
문제는 정올(<http://jungol.co.kr/>)에서 풀고, 이 레포에 **Pull Request(PR)** 로 제출합니다.

## 제출 방법 (git 몰라도 됩니다)

1. GitHub에 로그인하고, 위 표에서 **푼 문제 폴더**를 누릅니다.
2. 파일 3개를 준비합니다. 이름은 **본인 GitHub 아이디**로 합니다.

   | 파일 | 내용 |
   |---|---|
   | `아이디.c` | 정답 코드 (언어 자유: `.cpp` `.py` `.java` ...) |
   | `아이디.png` | 정올 '맞았습니다' 결과 캡처 |
   | `아이디.md` | 풀이 요약 + AI 사용 여부 ([템플릿](_template/풀이템플릿.md)) |

3. 오른쪽 위 **Add file → Upload files** → 파일 3개를 끌어다 놓습니다.
4. 아래 **Propose changes** → **Create pull request** 를 누릅니다.
   - PR 제목: `[2회차] 이름` (예: `[2회차] 홍길동`)
5. PR 아래 **자동 검사(Check submission)** 가 초록색 ✅ 인지 확인합니다.
   - ❌ 이면 메시지를 읽고 고쳐서 다시 올리면 됩니다.

> 문제마다 따로 올려도 되고(PR 여러 개), 한 문제씩 끝날 때마다 올려도 됩니다.
> 처음 업로드할 때 GitHub가 자동으로 내 계정에 Fork(복사본)를 만들어 줍니다. 그대로 진행하면 됩니다.

## 규칙

- **마감:** 각 회차 마감 시각까지 PR이 열려 있어야 제출로 인정합니다. 마감 후 수정은 반영하지 않습니다.
- **본인 파일만** 올립니다. 다른 사람 파일이나 공용 파일을 건드리면 자동 검사가 실패합니다.
- **AI 활용:** 본인 힘으로 먼저 고민하는 것을 권장합니다. AI의 도움을 받았다면 풀이 `.md` 에
  어떤 고민을 했는지와 **AI에 입력한 프롬프트 원문**을 반드시 적어 주세요.
- 공개 레포이므로 다른 사람의 제출물을 볼 수 있지만, 그대로 옮기는 것은 금지입니다.
- 개발 재학생(신입·기존) 평가 대상이며, 총 해결 문제 비율 미달 시 제명/경고 규정이 적용됩니다.

문의는 교육부장에게 카카오톡으로 해 주세요.
