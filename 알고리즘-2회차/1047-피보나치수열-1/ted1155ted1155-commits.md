앞의 두 수를 더하면 다음 수가 되는 규칙을 이용한다.
두 변수에 앞의 두 수를 저장하고 반복문으로 값을 갱신한다.

로직
1. a를 0, b를 1로 초기화한다.
2. next에 a + b를 저장한다.
3. a에 b를 저장하고 b에 next를 저장한다.
4. n번 반복한 뒤 a를 출력한다.

시간 복잡도: O(n)
공간 복잡도: O(1)


a = b를 먼저 실행하면 기존 a 값이 사라진다.
따라서 next에 두 수의 합을 먼저 저장한 다음
a와 b를 변경해야 한다.
