1과 3부터 시작하는 피보나치수열을 계산하면서,
입력한 n 이하의 항 중 짝수만 합계에 더한다.

로직 
1. a를 1, b를 3, sum을 0으로 초기화한다.
2. a가 n 이하인 동안 반복한다.
3. a % 2 == 0이면 sum에 a를 더한다.
4. next에 a + b를 저장하고 a와 b를 갱신한다.
5. 반복이 끝나면 sum을 출력한다.

예제 확인
n이 50이면 수열은 다음과 같다.

1, 3, 4, 7, 11, 18, 29, 47

짝수인 4와 18을 더하면 22가 된다.

코드에서 확인할 부분
n은 항의 개수가 아니라 수열 값의 상한이다.
따라서 반복 조건은 a <= n으로 작성한다.

짝수 여부는 a % 2 == 0으로 판단한다.
수열의 값과 합계는 long long으로 저장한다.

시간 복잡도: O(log n)
공간 복잡도: O(1)
