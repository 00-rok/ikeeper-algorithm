# 문제번호 — 문제 제목
1697 - 큐(queue)

- 이름: 장현석
- 결과: ✅ 맞았습니다

## 핵심 아이디어

- 큐를 구현하는 문제이니 큐 클래스에 배열 필드를 넣고 인큐, 디큐, 사이즈 메서드를 만들어주면 된다 

## 로직 요약

1. enqueue: 제일 끝에 아직 값이 들어가지 않은 배열 인덱스에 값을 삽입하고 해당 값 리턴
2. dequeue: 배열 제일 앞에 있는 값을 뺴내고 각 인덱스의 값을 한칸씩 앞으로 이동, 뺴놨던 값을 리턴
3. size: 해당 객체의 tail 필드는 배열에 있는 원소의 개수이기 떄문에 바로 리턴

**시간 복잡도:** O(n)

## 막혔던 부분 / 배운 점

- dequeue에서 tail을 --하는걸 깜빡해서 수정
