## 제출

각 문제 폴더에 들어가서 파일 3개를 올립니다. 파일 이름은 **본인 GitHub 아이디**로 합니다.

```
1102-스택/
├── 본인아이디.c      ← 정답 코드 (언어 자유)
├── 본인아이디.png    ← 정올 '맞았습니다' 캡처
└── 본인아이디.md     ← 풀이 요약 + AI 사용 여부
```

- 문제 폴더 → **Add file → Upload files** → 파일 3개 끌어다 놓기 → **Propose changes** → **Create pull request**
- 문제마다 따로 올려도 되고(PR 3개), 한 번에 올려도 됩니다.
- 못 푼 문제는 올리지 않아도 됩니다. 고민한 내용을 남기고 싶으면 `본인아이디.md` 만 올려도 됩니다.
