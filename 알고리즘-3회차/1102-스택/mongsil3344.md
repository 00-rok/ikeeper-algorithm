# 문제번호 — 문제 제목
1102 - 스택 (stack)

- 이름: 장현석
- 결과: ✅ 맞았습니다

## 핵심 아이디어

- Stack 클래스를 만들고 배열 필드와 push, pop, size 메서드를 구현해주면 된다

## 로직 요약

1. 스택을 만든다
2. 만든 스택에 값을 넣고 빼고 개수를 출력하는 함수를 정의
     push: 값을 넣고 top 증가시키기
     pop: 값을 변수에 담아두고 top 감소시키고 리턴하기
     count: top 출력
3. main 함수에서 switch문으로 입력을 받아서 처리

**시간 복잡도:** O(1)

## 막혔던 부분 / 배운 점

- 코틀린 처음 써봤는데 for문 문법이 특이해서 헤맴
- 자꾸 오답뜨길래 봤더니 pop() 에서 top-1이 아니라 top을 찾고있었음
